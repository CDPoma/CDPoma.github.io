DemocraciaBot

El robot con el que los servidores de Democracia leen fuentes públicas

Qué es

DemocraciaBot es el rastreador de Democracia, una app de votación ciudadana no oficial. Lo ejecutan funciones del servidor de la app (no hay ningún programa en el móvil de nadie) para traer a la app las leyes, decretos y elecciones en cuanto se publican. Se identifica siempre así:

User-Agent: DemocraciaBot/1.0 (+https://cdpoma.github.io/democracia/bot.html)

Qué lee

  • El BOE (su API de datos abiertos: sumario diario y legislación consolidada, y la página de texto de cada norma que su robots.txt permite).
  • Las referencias del Consejo de Ministros (La Moncloa).
  • La lista de próximas elecciones de IFES ElectionGuide. Su robots.txt lo declara «solo referencia» (Content-Signal: use=reference): solo enlazamos y resumimos.
  • La búsqueda pública de Bluesky, mediante su API, para contar cuántas veces se menciona cada norma.

A 21 de noviembre de 2026 hay otras fuentes preparadas pero sin activar: el Congreso de los Diputados y el Senado (sus datos abiertos), los canales RSS de una lista fija de medios (de cada noticia se guardaría solo el titular, el medio, la fecha y el enlace, nunca el artículo), la búsqueda pública de Mastodon y las webs de los partidos (para localizar el PDF del programa electoral). Cuando se activen, aplican las mismas reglas de abajo y esta página se actualizará.

Cómo respeta tu sitio

  • robots.txt primero. Antes de pedir una dirección lee el robots.txt del dominio (lo guarda 24 horas). Si lo prohíbe, no la pide. Si hay reglas para DemocraciaBot, aplica solo esas; si no, las de *. No interpreta Crawl-delay, pero respeta siempre la pausa que sigue.
  • Pausa mínima de 5 segundos entre dos peticiones al mismo dominio, con un límite de 30 segundos por petición.
  • Reintentos con calma: hasta 3 reintentos con espera creciente solo ante un error de servidor o de red (nunca ante un 4xx), y si una fuente falla repetidamente, espera cada vez más (hasta 24 horas) antes de volver.
  • No sale de un dominio sin mirar el robots.txt del dominio de destino.
  • Pocas visitas: cada fuente se consulta al ritmo al que publica (desde cada 15 minutos en las horas de más publicación del BOE y los martes del Consejo de Ministros, hasta una vez al día) y un documento ya guardado, con la misma dirección y huella, no se vuelve a analizar.

Qué guarda

Los datos que son públicos por naturaleza (título, organismo, fecha, enlace) y, de los documentos oficiales, una copia archivada con su huella SHA-256 y la fecha de captura, para poder comprobar mañana que no se ha cambiado. Siempre enlazamos a la fuente original. Si una web no permite copiar, solo guardamos el enlace.

Qué no hace

No entra en zonas con contraseña, no rellena formularios, no se hace pasar por un navegador ni por otro robot y no evita bloqueos.

Quiero que no pase por mi web

Añade a tu robots.txt:

User-agent: DemocraciaBot
Disallow: /

Lo respetará la próxima vez que lo lea (como mucho, en 24 horas). Si prefieres otra cosa, o notas algún problema, escríbenos a gabrielmicovictoria@gmail.com. Las peticiones salen de servidores en la nube y no hay una dirección IP fija que podamos darte.

DemocraciaBot

The robot Democracia’s servers use to read public sources

What it is

DemocraciaBot is the crawler of Democracia, an unofficial citizen voting app. It is run by functions on the app’s server (no program runs on anyone’s phone) to bring laws, decrees and elections into the app as soon as they are published. It always identifies itself like this:

User-Agent: DemocraciaBot/1.0 (+https://cdpoma.github.io/democracia/bot.html)

What it reads

  • Spain’s BOE (its open-data API: daily summary and consolidated legislation, and the text page of each rule that its robots.txt allows).
  • The Council of Ministers references (La Moncloa).
  • The list of upcoming elections from IFES ElectionGuide. Its robots.txt declares “reference only” (Content-Signal: use=reference): we only link and summarise.
  • The public search of Bluesky, through its API, to count how often each law is mentioned.

As of 21 November 2026 other sources are prepared but not switched on: the Congress of Deputies and the Senate (their open data), the RSS feeds of a fixed list of media (from each story only the headline, the outlet, the date and the link would be kept, never the article), Mastodon’s public search and party websites (to find the PDF of the election manifesto). When they are switched on, the same rules below apply and this page will be updated.

How it respects your site

  • robots.txt first. Before requesting an address it reads the domain’s robots.txt (cached for 24 hours). If it forbids it, the bot does not request it. If there are rules for DemocraciaBot it applies only those; otherwise those for *. It does not interpret Crawl-delay, but it always keeps the pause below.
  • At least 5 seconds between two requests to the same domain, with a 30-second limit per request.
  • Gentle retries: up to 3 retries with growing waits only on a server or network error (never on a 4xx), and if a source keeps failing it waits longer each time (up to 24 hours) before coming back.
  • It does not leave a domain without checking the destination domain’s robots.txt.
  • Few visits: each source is read at the pace it publishes (from every 15 minutes in the BOE’s busiest hours and on Council of Ministers Tuesdays, down to once a day) and a document already stored, with the same address and fingerprint, is not analysed again.

What it stores

Data that is public by nature (title, body, date, link) and, for official documents, an archived copy with its SHA-256 fingerprint and capture date, so anyone can later check it has not been changed. We always link to the original source. If a site does not allow copying, we keep only the link.

What it does not do

It does not enter password-protected areas, fill in forms, pose as a browser or another robot or evade blocks.

I do not want it on my site

Add this to your robots.txt:

User-agent: DemocraciaBot
Disallow: /

It will obey the next time it reads it (within 24 hours at most). If you prefer something else, or notice a problem, write to gabrielmicovictoria@gmail.com. Requests come from cloud servers and there is no fixed IP address we can give you.
